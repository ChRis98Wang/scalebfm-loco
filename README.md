# ScaleBFM-Loco

An experimental Unitree G1 locomotion and whole-body motion-tracking project,
built as an unofficial engineering extension of
[ScaleBFM](https://github.com/zengweishuai/ScaleBFM).

> [!IMPORTANT]
> This repository is an early README-only snapshot. Source code is still under
> active development and is not included in this initial publication. Future
> demos will be qualitative simulator rollouts, not evidence of a complete
> ScaleBFM reproduction or real-robot safety.

## High-dynamic controller demos

The final media will be added here after motion-source publication rights and
the exact policy checkpoint have been recorded. Each inline preview will link
to its full MP4 recording.

## Scope

- Robot: Unitree G1, 29 actuated joints
- Controller: Transformer actor-critic trained with PPO for reference tracking
- Status: simulation research prototype; real-robot validation is not established

The upstream ScaleBFM authorship remains with the original project and paper
authors. No dataset, motion archive, checkpoint, training log, or robot asset is
distributed in this demo snapshot.
