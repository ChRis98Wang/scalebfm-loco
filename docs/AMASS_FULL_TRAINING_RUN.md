## 指标解释与下一次汇报注意点

1. 基础 checkpoint 携带全局编号 22199。短训最后编号 22248，第二阶段复用该编号，
   最后预计为 23197；两阶段实际更新是 50 + 950，不能只用全局编号差计算。
2. 第二阶段预计真正触发评估的编号为 22499、22999。当前运行器会在相邻训练轮重复
   写入上次评估结果，统计时只取 `(step + 1) % 500 == 0` 的真实评估点。
3. 内置通过率采用单条评估窗口最大身体位置误差不超过 0.5 米的标准，阈值较宽松；
   不代表视觉接触质量、全部语义任务、真实机器人安全性或 BFM 复现百分比。
4. 1,000 次是本轮试训预算，不保证收敛。最终权重需要与官方权重做同条件独立比较，
   并检查不同动作类别的回放与误差；不得凭文件生成或训练 reward 声称效果提升。
5. 未逐位恢复仿真与随机数状态，两阶段运行不等价于一次不间断 1,000 更新的轨迹。
