# 数据升级与 ScaleBFM 主线完成路线

更新：2026-09-09。用户授权：由开发方选择更好的数据方案，并继续完成 ScaleBFM。

## 决策

保留现有 7,174 条训练动作和官方模型作为可回退基线；建立新的候选数据版本。
不把 UMR 输出一律当作更好的数据，也不继续使用已在八模式回归中退步的权重作为默认。

比较三个候选方向：旧 ScaleRetarget、碰撞脚底高度修正、真正的 SMPL-X 表面驱动 UMR。
先检查同源、同时间轴与几何，再冻结官方策略测试可跟踪性，最后做等预算训练 A/B。
只有跨模式、跨数据源的结果通过后才扩大替换范围。旧文件、旧索引、旧检查点不覆盖。

### 为什么表面适配器不是 Behavior 训练

Stage I 学的是 T-pose 中人体表面点与机器人表面点的对应；Stage II 求解每帧机器人姿态。
真正的行为控制策略仍是 IsaacLab 中以这些参考动作训练的 Transformer actor-critic + PPO。
新数据生产成功不代表策略已经学会这些行为。

新适配器固定网格三角面和重心坐标，在每个姿态的真实 SMPL-X 网格上重新计算采样点与法向量，
因此保留蒙皮变形，而不是把全部点刚性绑到最近关节后运输。保留完整静态 betas；性别模型不匹配时拒绝静默替换。
输入关节层级、米制、Z-up、朝向变换、真实 50 Hz 时钟均有显式记录。

SMPL-X 是可变形皮肤，不能照搬该 BVH 实现的刚性 T-pose 偏差补偿：本适配器强制 `tpose_offset=0`。
旧本地数据使用优化后的中性 shape，新适配器使用源 shape；所以后续比较是整个数据流程的比较，
不能把全部差异单独归因于 UMR 求解器。
