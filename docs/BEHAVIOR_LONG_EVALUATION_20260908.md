## 判定规则与解释边界

每种 mask 比较四项：激活连杆全局位置均值、姿态均值、激活连杆最大偏差门槛通过率、
全部 14 个参考连杆最大偏差门槛通过率。偏差门槛为任意有效时刻任意相关连杆 >0.5 m；
它不是跌倒检测、接触稳定、抓取成功率或在线 XYZ 到达率。

逐片段先取均值，再等权汇总。除总体八模式外，旧数据和 KIT 分别做八模式无退步检查，
不能让新数据改善掩盖旧行为遗忘。位置/姿态均值容差仅 `1e-6`，两个通过率不可降低。
这是预定义门槛，不是统计显著性检验或收敛证明；两个集合均为开发验证集。

`status.json.result=COMPLETE` 表示 16 组物理评估、比较及来源复核执行完成。
真正的质量判定是独立字段 `quality_result=PASS_NO_REGRESSION/FAIL_NO_REGRESSION`；
比较器返回码 0 不代表质量通过。不论哪种结果，都不自动推广模型。
