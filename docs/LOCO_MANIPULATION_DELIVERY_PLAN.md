# Loco-manipulation 演示实现与验收路线

状态：**DRAFT，尚未实施或训练**。更新：2026-09-09。
本文定义 ScaleBFM 仿真主线之后的分阶段演示；新增文档不代表任何演示已经成功。

## 前置证据与能力边界

- 先完成主线导出数值一致性、八 mask 与 global/local 控制契约、MuJoCo 实际闭环和有界进程清理。
- 导出/Sim2Sim 是仿真阶段的接口与闭环验收，不等于实物部署、搬箱能力或论文全部实验复现。
- 当前已完成的 PPO 长训练仍未过 no-regression：总体 0/8、来源分层 0/16；保留官方权重作为基线。
- UMR 的冻结策略对照也不是新策略学习成功证据；后续学习协议见 [UMR A/B 草稿](UMR_BEHAVIOR_AB_PROTOCOL_20260909.md)。
- BFM 提供身体控制底座。接近、建立接触、维持夹持和放置需要任务条件、参考规划及可能的新任务训练。
- 同源 motion、动作文件名中的 `box`、人体看似搬运的姿态，都不等于机器人监督任务成功标签。

## 共同实现约束

- 使用现有 body-only G1 29DoF 和箱子资产；不添加 Dex3、不要求手指，靠双腕/前臂夹持形成接触。
- 保留 pelvis、上肢和双腕目标的 XYZ 与姿态，明确世界坐标、机器人局部坐标和目标时间戳。
- 主演示使用世界坐标任务目标；local 控制另报相对任务误差和全局漂移，不能冒充绝对落区精度。
- 箱子是有质量、惯量、碰撞和自由关节的动态物体，运动来自重力、真实碰撞与机器人施加的力。
- 禁止焊接、绑定、附着关节、抓取后锁定箱子，以及直接写箱子位姿/速度轨迹；仅 episode reset 可设置初态。
- 若使用升降台或放置台，必须是场景中的真实支持几何，不能用隐藏支撑代替夹持。
- 每次 step 由策略给机器人关节目标，再经 PD/执行器推进物理；目标规划器不得直接操纵机器人或箱子状态。
- 固定机器人/物体资产、质量惯量、摩擦、接触求解、控制频率、PD/力矩限幅、参考生成器与策略版本。
- 接触参数目前未实物标定。所有成绩限定于已声明的仿真配置，不作硬件可行性或负载能力承诺。

## D0：带上肢目标的行走

目的：先展示统一身体控制，不包含物体接触或搬运成功声明。

1. 输入一条 1 m 的 pelvis 世界坐标行走路线，并给双腕连续 XYZ/姿态目标；包含至少一次 5 cm 上肢高度变化。
2. 依次验证适用的上肢/移动上肢 mask；记录每种 mask 实际激活的身体名单，不把不受控 link 的误差冒充受控误差。
3. 报告目标与实际 pelvis/腕部轨迹、到达时间、XYZ 与旋转误差、足部接触、跌倒和关节/力矩饱和。
4. 初始验收：20 s 内 pelvis XY 到终点 0.15 m 内；受控腕位置 RMSE ≤ 0.10 m、旋转 RMSE ≤ 0.30 rad，无跌倒。
5. 交付固定回放命令、目标文件、逐步指标与代表性视频。D0 可先演示，但视频须明确“无物体接触”。

## D1：站立双臂夹轻箱、抬起、保持、放下

目的：隔离接触操作，先证明站立时能够真实建立和维持夹持。

1. 初版箱子质量建议 1 kg；尺寸/惯量沿用资产并记录，支持台高度与初始手臂目标在可达范围内固定。
2. 状态顺序为对准 → 接近 → 双侧接触 → 抬升 → 保持 → 降低 → 支持面承重 → 松开撤臂。
3. 状态切换依赖箱子/接触物理测量；接触未建立不得仅凭预定时间宣称进入夹持阶段。
4. 箱子底面比初始支持面高至少 0.08 m，保持至少 2 s；保持时 roll/pitch 偏差 ≤ 15°。
5. 放回预先固定的支持区域，双臂撤离且箱子稳定至少 1 s；整个过程 20 s 超时，机器人无跌倒。
6. 保存成功和失败轨迹。只有下述接触、抬升、保持、放置条件同时成立才计 D1 成功。

## D2：走近、夹持、搬运 1 m、放入指定区域

目的：把导航到达、接触操作与行走稳定性合并为完整任务。

1. 从与箱子分离的机器人初态开始，走近真实支持台上的箱子；D1 的夹持测量逻辑原样复用。
2. 双侧接触成立后抬箱，保持箱子离地/离台，携带到距拾取区域水平距离至少 1 m 的指定区域。
3. 目标区域固定为可见的 0.5 m × 0.5 m 支持面区域；箱体投影必须完整位于区域内，不只检查中心点。
4. 放置姿态相对目标 yaw 偏差 ≤ 15°、roll/pitch 偏差 ≤ 10°；放下后松开并撤臂。
5. 箱子稳定 1 s，线速度 ≤ 0.05 m/s、角速度 ≤ 0.10 rad/s；机器人无跌倒，40 s 内完成全部阶段。
6. 携带途中落地、掉箱、接触丢失后未能保持负载、到达错误区域或超时均为失败；不得剪掉失败阶段拼接演示。

## 物理成功测量

| 测量 | 需要记录和采用的判据 |
|---|---|
| 双侧接触 | 固定允许接触箱子的左右腕/前臂 body 名单；分别由实际 contact pair/法向力识别，初始阈值各 ≥ 0.2 N 且连续 0.2 s |
| 持续夹持 | 从离开支持面到目标放置阶段，双侧有效接触覆盖率 ≥ 90%，任一侧连续丢失不得超过 0.10 s；支持面落稳后松开不计丢失 |
| 箱子 6D 位姿 | 逐步记录真实自由体位置与单位四元数、线/角速度；与目标姿态比较，不能读取规划器目标充当实际状态 |
| 离地/离台 | 用实际箱体碰撞几何最低点相对原支持面的距离测量，同时检查支持面接触已消失；D1 保持段最低间隙 ≥ 0.08 m |
| 滑落 | 记录箱子相对左右夹持部位的位姿；保持/携带阶段出现相对平移漂移 > 0.05 m、意外支持面接触或上述接触丢失，计滑落失败 |
| 搬运距离 | 从物理拾取位姿到物理放置位姿的水平位移 ≥ 1 m；箱子在机器人携带阶段完成，不能靠放下后滑动补足 |
| 落区与释放 | 箱体投影完整落区、姿态达标、真实支持接触成立、双臂解除接触，且满足稳定时间和速度阈值 |
| 跌倒/超时 | 记录 pelvis 高度/倾斜、非预期躯干或头部碰地；初始保护阈值为高度 < 0.30 m 或倾斜 > 75°，另检查各阶段/任务时限 |

上述数值是首版仿真工程验收草案，执行前须冻结；不代表已经标定或已经达到。
指标时间戳必须对应同一物理时刻；MuJoCo 积分后更新所需的 FK/接触动力学派生量，再采集指标，不能混用上一子步数据。
跌倒保护和跟踪阈值只是判据组成部分，不能用“策略输出有限”或“脚本退出码 0”代替任务成功。

## 验证、晋级与交付

- 开发参考、训练初态与验收初态分开保存；按原始 motion/source 身份隔离，重打包后不得把验证来源改为 train。
- 每阶段先完成工程 smoke，再做预先固定的 20 组初态 × 3 个独立 seed，共 60 次验收 episode。
- D0 扰动机器人初态和目标；D1/D2 覆盖机器人/箱子相对 XY、朝向和箱子姿态；建议初版 XY ±0.05 m、yaw ±10°，分布与 seed 在验收前冻结。
- D0/D1 初始晋级标准为至少 54/60 成功且每个 seed 至少 17/20；D2 首版交付也采用相同门槛，不以最佳视频替代成功率。
- 报告每阶段总成功率、逐 seed/初态结果、二项置信区间与失败原因；不得删除失败、重试后只记成功或看结果调门槛。
- 修改质量阈值、接触参数、训练奖励或参考规划器后发布新版本；重新验证时保留旧结果，明确哪些初态已参与开发。
- 交付包含场景与目标配置、策略/数据/代码 SHA、可复现命令、阶段事件和逐步物理指标、全部 episode 汇总及成败视频。
- 每阶段报告分别给出 `execution_complete` 与 `task_success`；控制链完成但任务失败仍按失败汇报，不自动提升为默认策略。
- D0 → D1 → D2 分阶段推进；若需要任务 PPO/其他学习，另建训练预算与验收协议，不能把 BFM 已有权重视为已训练搬箱策略。

本路线限定本地仿真演示。实物接触、真实负载、硬件时延和设备安全需要独立条件与标定，不包含在本次演示成功声明中。
